Study parameters

The six primary geometry variables of the self-heating study. All lengths are in micrometres (1 nm = 0.001 µm). Every other coordinate in the structure is recomputed from these and from the design constants below.

µm
Vertical (Y) extent of each sheet. Sets the sheet pitch, the gate bands and the device height — the dominant term in the thermal path out of the channel.
µm
Transverse (Z) extent of each sheet. Drives the HfO2 collars, the gate bridges and the pMOS offset.
µm
Gated length in X. Sets the channel segment, the gate metal and both junction planes.
µm
Si3N4 between gate and pad, each side. Also the source-to-gate and drain-to-gate distance, and a poor thermal conductor in the escape path.
µm
Length of each source and drain pad in X. The pad height and width are not independent: they follow the sheet stack and the gate envelope.
sheets
Sheets per transistor. Every dependent band, spacer piece, collar and doping placement is rebuilt from this. The structured V8 formats are written for 3; other counts emit step-by-step.

Doping concentrations

Active concentrations in cm−3, written straight into the profile definitions and bound to named regions. The channel value is shared by both devices, as are the extension and pad values — the species differ, the magnitudes do not.

The channel is effectively undoped: at 3e17 a 20×6×30 nm channel holds about one dopant atom, so the threshold would be a single-atom lottery. Vt comes from the gate workfunction instead, set in sdevice.cmd.

Generation options

One at a time varies each parameter while holding the other two at the values above. Full grid takes every combination.

Tick the variables to sweep and give each a comma-separated list. Unticked parameters hold the value set above. A full grid is the product of every ticked list, so it grows quickly — the case count below is live.

nm
Scales every sdedr:define-refinement-size in the generated SCM, so it changes the mesh snmesh actually builds. Smaller = finer = more elements and longer solves; larger = coarser = cheaper. The ratios are preserved, so the channel, the gate dielectric and both junctions stay finer than the bulk. 2 nm is the baseline and emits the refinement lines unchanged.
